
# DataShield

## Overview
DataShield is an end-to-end Cybersecurity Data Engineering project that processes real-world vulnerability data and transforms it into structured information for analysis.

## Dataset
CISA Known Exploited Vulnerabilities (KEV) Catalog

## Dataset Source
https://github.com/cisagov/kev-data

## Technologies
- Python
- Pandas
- PostgreSQL
- SQL
- Apache Airflow
- Git and GitHub

## Project Objectives
- Data Ingestion
- Data Cleaning
- Data Validation
- Data Transformation
- Database Storage
- Workflow Orchestration
- Data Quality Monitoring
- Security Analytics
